# Packet Tracer Labs

## Overview

Welcome to my Network Engineering Lab portfolio.

This repository documents my hands-on networking journey while building a professional networking portfolio as I prepare for the Cisco Certified Network Associate (CCNA 201-301) certification. The goal of this repository is to move beyond theory and further develop the practical skills required for Network Engineering roles by building, documenting, and troubleshooting real-world networking scenarios using Cisco Packet Tracer.

I will be working through the set of networking labs provided with Jeremy's IT CCNA course while expanding on the concepts through additional documentation, network diagrams, configuration examples, and lessons learned.
